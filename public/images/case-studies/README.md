# Case Study Images

Put project images here so case studies can reference them with stable paths.

Recommended structure:

- `public/images/case-studies/fluent/`
- `public/images/case-studies/english-quest/`
- `public/images/case-studies/webgl-game/`

Recommended filenames:

- `hero.jpg`
- `gallery-1.jpg`
- `gallery-2.jpg`
- `gallery-3.jpg`

When you add your own images, update the corresponding paths in `src/data/projects.ts`.
